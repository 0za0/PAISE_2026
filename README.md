# Project Software Engineer Simulator (Game)

Ein browserbasiertes Idle-/Clicker-Spiel im Stil von Cookie Clicker. Der Spieler baut sich als Software Engineer ein immer stärker automatisiertes Entwicklungsteam auf: vom Praktikanten bis zum KI-Copiloten. Jede Automatisierung hat einen Preis, nämlich Tech Debt.

Der Spieler klickt, um Code zu schreiben, und verdient dafür Tokens (die Spielwährung). Mit Tokens kauft er Generatoren (Praktikant, Junior Dev, Senior Dev, KI-Copilot). Diese produzieren automatisch Tokens pro Sekunde (TPS).

Anders als bei klassischen Clickern erzeugen Generatoren einen Nebeneffekt: Tech Debt. Steigt die Debt, sinkt die Produktion. Der Spieler muss also ständig abwägen: noch schneller wachsen oder einen Refactoring Sprint einlegen, der die Debt abbaut, aber kurzfristig Produktion kostet.

Zielgruppe: ITler, Nerds


Projektziel

Innerhalb des Semesters entsteht ein spielbares Browser-Spiel (MVP), das den kompletten Kernloop abdeckt: Klicken → Generatoren kaufen → Tech Debt entsteht → Refactoring → Spielstand bleibt erhalten. 

Weitere Mechaniken (Incidents, Energie, Achievements, Prestige …) sind priorisiert und werden nur bei verbleibender Zeit umgesetzt.
